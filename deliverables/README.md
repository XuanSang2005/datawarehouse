## Required structure

**In-class presentation slides** (10 minutes, every member presents):
1. Introduction · 2. Business problem definition · 3. Introduction to proposed solution ·
4. What you have done so far · 5. Plan to complete · 6. Additional details

**Final report and final slides:**
1. Introduction · 2. Business problem definition · 3. Proposed solution · 4. Application development ·
5. Evaluation · 6. Conclusion · References · **Appendix 1. Teamwork report**
